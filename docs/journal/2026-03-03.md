## 技術的決定事項

### TD-1: 言語選択 - TypeScript
- **選択理由**: 型安全性、IDE補完、保守性
- **代替案**: Plain JavaScript
- **判断**: ユーザー要望によりTypeScriptを採用

### TD-2: ビルドツール - Vite
- **選択理由**: 高速、モダン、TypeScript統合が優秀
- **代替案**: webpack, esbuild
- **判断**: シンプルさと速度のバランス

### TD-3: ブロック手法 - CSS injection
- **手法**: `pointer-events: none` + 視覚的フィードバック
- **対象セレクタ**: YouTube component selectors (ytd-*)
- **判断**: Phase 1はシンプルなCSS戦略で開始
