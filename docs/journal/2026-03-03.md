## 技術的決定事項（Phase 4追加）

### TD-7: Badge検出戦略
- **セレクタ**: `.yt-badge-shape__icon`
- **検出方法**: querySelector()でバッジアイコンの存在確認
- **適用**: 動画要素全体に除外クラス付与
- **理由**: YouTubeのバッジUI構造に準拠

### TD-8: MutationObserver実装
- **監視対象**: document.body全体（subtree: true）
- **監視タイプ**: childList（子要素追加/削除）
- **最適化**: debounce 300msで処理頻度制限
- **理由**: YouTubeの動的コンテンツ読み込みに対応

### TD-9: オーバーレイ強度
- **opacity**: 0.05（95%透明）
- **blur**: 30px（大幅ぼかし）
- **grayscale**: 100%（完全白黒）
- **brightness**: 0.5（暗度50%）
- **理由**: ユーザー要望「絶対に見分けつかないレベル」に対応

## 学んだこと・気づき（Phase 4追加）

### うまくいったこと
- MutationObserver + debounceで効率的な動的監視
- CSSクラスベースの除外が柔軟で保守しやすい
- console.logで開発時のデバッグが容易

### 技術的発見
- YouTubeは`.yt-badge-shape__icon`でバッジを表現
- MutationObserverは高頻度で発火するためdebounce必須
- CSS filter複数組み合わせで強力な視覚効果
