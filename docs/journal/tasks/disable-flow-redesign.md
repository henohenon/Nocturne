# タスク: 許可対象の見直し・夜間スケジュール・無効化フローの刷新

## 実施したタスク

### 完了
- 許可対象を「公式アーティスト動画（ライブ除く）+ 再生リスト/ミックス」に変更、ライブは全ブロック
- 夜間スケジュール（19:30〜05:00 自動無効）
- 無効化を専用ウィンドウ（危険デザイン、デフォルト30分・最大120分）に変更
- 連続無効化の確認アラート（前回終了から60分以内を連続とカウント）、クールダウン廃止
- 無効化状態を storage に一元化し全タブ共通に（popup→タブのメッセージングを廃止）、`tabs` 権限を削除
- ブロック済み項目の「新着」バッジ漏れを修正

## 技術的決定事項

### TD-1: 音楽判定
- **決定**: メタデータ行のアイコンの aria-label（「公式アーティスト チャンネル」/ "Official Artist Channel"）で判定
- **代替案**: SVG パス形状 / 内部データ
- **理由**: 認証済みバッジと同じクラスのため区別はラベルか形状のみ。ラベルの方が読みやすく直しやすい。ロケール依存（ja/en のみ）は許容

### TD-2: 状態の置き場所
- **決定**: chrome.storage に一元化、content script は変更イベント + 15秒ごとの再評価
- **理由**: 専用ウィンドウからはアクティブタブ宛てメッセージが使えない。全タブ共通化とタブ跨ぎの抜け穴解消も兼ねる。スリープ復帰やスケジュール境界も同じ仕組みで拾える

### TD-3: 連続の定義
- **決定**: 前回の無効化終了（時間切れ or 手動再有効化）から60分以内の無効化を連続とする
- **補足**: 「今もそういう実装では？」とのことだったが、旧実装は回数を数えておらずクールダウンのみだった
