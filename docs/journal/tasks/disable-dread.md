# タスク: 封印を解く画面の恐怖演出・連続確認の専用画面・ブロック表示のグレー化

## 実施したタスク

### 完了
- 無効化ウィンドウ: 閉じた目のマークが開いて赤い目になる（開眼アニメーション + 7秒ごとのまばたき）、瞳がカーソルを追う、背景は心拍のリズムで脈打つ
- 連続無効化の確認: ブラウザ標準の confirm を廃止し、ウィンドウ内の専用画面に
  - 「これで n 回連続です。」「本当に必要ですか？？？」「もし虚ろならば、今すぐ散歩に行きましょう。」
  - 「散歩に行く」（閉じる）/「それでも解く」（無効化）。後者は 3秒 ×（n−1）、最大15秒ロック
  - Esc で散歩に行く
- YouTube 上のブロック表示をグレーに（サムネイル・アイコンはグレー + 明るめグレーのマーク、文字はグレーの帯）

## 技術的決定事項

### TD-1: 開眼マークの形
- **決定**: アイコンの三日月とまつ毛を下まぶたとしてそのまま残し、その上に上まぶた・暗い白目・光る赤い虹彩・針のような瞳孔
- **代替案**: 上まぶたにまつ毛を付けた一般的な目
- **理由**: 後者はよくある可愛い目になった。前者は閉じた状態からの連続性があり、目の怪物のような不気味さが出る

### TD-2: 確認画面の出し方
- **決定**: ウィンドウ内でフォームと確認画面を入れ替え、目は残して大きくする
- **代替案**: フォームの上に重ねるモーダル
- **理由**: 目に見られている状態を保ったまま問い詰められる。構造も単純

### TD-3: 待ち時間
- **決定**: 3秒 ×（n−1）、上限15秒。定数は config に
- **理由**: 連続するほど重くなる圧。上限で「壊れた」と感じさせない
