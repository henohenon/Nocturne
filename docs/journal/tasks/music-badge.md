# タスク: YouTube の音楽判定を広げる

## 実施したタスク
- ホームの「音楽」でブロックされていた項目（歌ってみた・カバー・ボカロ）を調査。公式アーティストの印はないが、再生時間バッジに ♪ が付いていた
- 許可条件に「再生時間バッジの ♪」を追加。ライブは引き続きブロック。CSS のみ
- README の説明と注意書きを更新

## 技術的決定事項

### TD-1: 音楽の目印
- **決定**: YouTube が付ける ♪（再生時間バッジ内のアイコン）
- **代替案**: タイトル・チャンネル名の文字列（「歌ってみた」「- トピック」など）で JS 判定
- **理由**: YouTube 自身の分類を借りれば CSS だけで済み、誤判定の責任も持たない。♪ が付かない音楽は取りこぼすが許容

## 検証結果
- ゲーム動画の関連: ♪ なし、ブロックのまま。ライブの lofi ラジオもブロックのまま
- 歌ってみた動画の関連: 旧ルール 4/4 ブロック → 新ルール 2/4（♪ 付きのカバー2件が通る、♪ なしのカバー1件と非音楽1件はブロック）

## 気づき
- ユーザーのスクショが決め手だった。ブロック前後の2枚を並べると ♪ が共通点として見えた
- ユーザーの見立て「判別不能では」は半分正しい。YouTube が ♪ を付けていない音楽は判別できない
