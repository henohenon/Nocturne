# タスク: 点々の演出パターン再検討と長時間の「やばさ」強化

## 実施したタスク
- 点々を R1（金 → 黒い円、中に赤い点）に。赤い点はまぶたと同じタイミング・動きで開き、それぞれ別の周期（5.3秒・8.9秒）でまばたき
- まぶたの開き方を「目全体が縦に伸びる」から「上まぶたがせり上がる」（L1）に
- 瞳・赤い点がそれぞれ自分の位置からカーソルを追う
- 90分超: 数字の色ずれ・ちらつき、120分で一瞬「見てるよ」。鼓動が速まり、闇が迫り、走査線。目（点々も）が見開き、瞳孔が縦に裂け、まばたきを止め、つまみを凝視。120分で画面が震える。添え字が「分。本気？」まで変化
- スライダー上端の色を赤黒から明るい深紅に（読める数字のまま、怖さは演出で）
- ツールバーの開眼アイコンの点々も黒い円に赤い点（32px・16px は赤いドットを手打ち）

## 技術的決定事項

### TD-1: 点々の形
- **決定**: R1 黒に赤い点（2D・フラット）
- **代替案**: 小さなまぶた付きの目、重瞳、血の涙、眼球（立体）、金の猫目、群れ など計20案近く
- **理由**: ユーザー判断。「立体より 2D でシンプルだけど圧がある」

### TD-2: まぶたの動き
- **決定**: L1 なめらか（少し行き過ぎて落ち着く）
- **代替案**: L2 ためらい、L3 震えながら
- **理由**: ユーザー判断

### TD-3: 長時間の表現
- **決定**: G2 壊れる + G3 部屋ごと
- **代替案**: G1 血（焦げた数字と垂れる血）
- **理由**: ユーザー判断

### TD-4: 凝視する条件
- **決定**: 90分超とドラッグ中だけつまみを見る
- **理由**: 常につまみを見ると、カーソルを追う演出が消えるため
