# タスク: 封印を解く画面の磨き込みとブロック表示の文字選択対策

## 実施したタスク
- 分数入力を標準のスピナーからスライダーに。5〜120分・5分刻み。数字・バー・つまみが同じ色で、0 白 → 30 金 → 90 赤 → 120 赤黒と変わる。100分を超えると数字が震える
- 開眼の演出: 金色の閉じた目（星の点々付き）から始まり、赤くなりながら開く。点々は本体と同時に小さな目になり、瞳はカーソルを追い、まばたきも一緒
- ツールバーの開眼アイコンにも点々の目（32px は書き出し、16px は赤いドット2つ）
- YouTube のブロック表示で文字を選択できないように（選択色で隠した文字が見えていた）
- 無効化ウィンドウの高さを 560 → 640（スライダー分）

## 技術的決定事項

### TD-1: 分数入力の形
- **決定**: スライダー
- **代替案**: −/+ ステッパー、プリセット（5/15/30/60/120）
- **理由**: ユーザー判断。長さが色の変化として目に見える

### TD-2: 点々の目の開き方
- **決定**: 小さなまぶた付きの目、本体と同時に開く。金の点がそのまま赤い瞳へ育ってから本物の瞳に入れ替わる
- **代替案**: まぶたなしの光る瞳、順番に遅れて開く
- **理由**: 金の閉じた目から途切れなく変わってほしい、全部同時に、というユーザーの要望

### TD-3: 文字選択対策
- **決定**: CSS の `user-select: none`（見せない）
- **代替案**: 文字化け
- **理由**: 文字化けは JS で YouTube の DOM を書き換える必要があり、「CSS だけで隠す」方針に反する

## ミス・想定外

- 120分の赤黒は、そのままだと暗くて読めない。にじみだけ明るい赤に
