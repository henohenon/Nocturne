# タスク: 封印を解いている間はツールバーのアイコンが開眼

## 実施したタスク
- 開眼アイコン（赤い枠・暗い赤のまぶた・光る赤い瞳）を作成。16px はドット打ち
- バックグラウンド（service worker）を追加し、手動で封印を解いている間だけ開眼アイコンに。時間切れは一回限りのアラーム、夜の始まりは1分ごとのアラームで拾う
- `isSealBroken` と単体テスト2件を追加（計14件）

## 技術的決定事項

### TD-1: どこまでやるか
- **決定**: ツールバーのアイコンだけ
- **経緯**: YouTube / X のタブの favicon を開眼させる・タイトルを文字化けさせる案も出たが、ユーザー判断で「サイト自体をハックするのはやめる」

### TD-2: 開眼アイコンの配色
- **決定**: 枠ごと赤（O2）。16px ではまぶたと瞳が同じ赤で潰れたため、まぶたを暗い赤、瞳を明るい赤に分けた
- **理由**: いつもの金から赤に変わることで、状態の変化が一目で分かる

### TD-3: 夜間の扱い
- **決定**: 夜は閉じた目のまま（正当な自由時間なので責めない）
