# Business: Allowlist Review, Night Schedule, Disable Flow Redesign

## Why
- Live streams pull attention like normal recommendations; the allowlist should cover only intentional listening (music by artists, playlists, mixes)
- Evenings are free time — the blocker should step aside automatically instead of requiring manual disables
- Manual disable is too easy (one click); friction and self-reflection should grow with repeated use

## Goals
- Allow: official-artist videos, playlists, mixes. Block everything else, including live
- Auto-off during 19:30–05:00
- Disabling requires a deliberate, uncomfortable step; repeated disables trigger a reflective prompt

## Non-goals
- Allowing only singing streams among lives (possible future option)
- User-configurable schedule UI
