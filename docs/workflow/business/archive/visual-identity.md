# Business: Visual Identity

## Why
- The extension now has a distinct mark (closed-eye crescent, night black + antique gold); the UI still looks generic (gray popup, hazard-tape warning page), so the product reads as three unrelated pieces
- A coherent look makes the checkpoint feel intentional rather than like a broken page — the blocker should look like it was placed there on purpose
- The name appears in several spellings (`NOCTURNE`, `Nocturne`); one consistent brand is easier to recognize

## Goals
- Every surface (popup, disable window, blocked items on YouTube) shares the mark's tone: dark, restrained, a little theatrical ("chuunibyou" gold noir)
- Name shown as `Nocturne` everywhere users see it
- The disable window keeps its job: disabling must still feel heavy and uncomfortable
- Night is free time by default, but some nights you want the seal anyway — let the user opt in for the night with one tap

## Non-goals
- Changing existing behavior (allowlist, schedule times, disable rules, copy semantics) — the night seal is the only addition
- Light theme for extension pages
- Store listing assets (screenshots, promo tiles)
