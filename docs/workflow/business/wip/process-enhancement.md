# Business Context: Process Enhancement

## Why

### Problems
1. **Roadmap not updated at task start** — tasks are added to roadmap only after completion, making the roadmap a history log rather than a live work tracker.
2. **lessons.md is a maintenance burden** — even as a pointer index, it's a separate file that must be kept current. The pointers point to docs that already exist; the indirection adds no value.

### Goal
- Roadmap reflects what is being worked on *right now*, not just what is done
- Failure knowledge is accessed contextually by reading relevant task logs and archived docs directly — no intermediary file needed

### Success Criteria
- process.md mandates roadmap update before any task begins
- lessons.md is deleted; rules instruct reading journal/tasks and workflow/archive for domain context
