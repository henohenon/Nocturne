# Journal Rules

Daily work logs in Japanese.

## When
- End of day (required)
- Key decisions (required)
- Phase completion (required)

## What
1. Tasks: done, in-progress, new
2. Decisions: options, choice, why
3. Learnings: worked/didn't, insights
4. Next: actions, blockers

## Format
- File: `docs/journal/YYYY-MM-DD.md`
- Template: `journal/template.md`
- Link commits with hashes
