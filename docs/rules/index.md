# Documentation Index

Overview of Workflow and Documentation for Smooth Project Progression

## Flow
backlog.md(Read Idea) → roadmap/(Update Road Map) → workflow/ (collect) (plan) (design & build)

- backlog.md — Idea list. AI will not edit it.
- roadmap/ — Only `roadmap/index.md` exists. AI must update roadmap before work.
- workflow/ — Implementation-level document. See [workflow/index.md](../workflow/index.md).
- journal/ — Daily work logs.
- rules/ — Must-read rules for ensuring smooth project execution.
