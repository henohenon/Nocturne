# Skill: workflow-status

Summarize the current project state.

## Steps

1. Read `docs/roadmap/index.md` — current phase and open tasks
2. Read the latest entry in `docs/journal/` — recent work and blockers
3. Check `docs/workflow/*/wip/` — in-progress design documents

## Output

- Current phase
- Recently completed tasks
- Open tasks and blockers
- Next actions (priority order)
