# Skill: journal

今日の作業ログを `docs/journal/YYYY-MM-DD.md` に書く（または更新する）。

## 手順

1. 今日の日付を確認（YYYY-MM-DD形式）
2. `docs/journal/<today>.md` が存在するか確認
3. 存在しない場合は新規作成、存在する場合は追記
4. `.claude/rules/journal.md` の形式に従って記述

## 記述内容

以下をこの会話の作業内容から抽出して書く：

- 実施したタスク（完了・進行中・新規）
- 技術的決定事項（選択肢・選択・理由）
- 学んだこと・気づき（うまくいったこと・課題・技術的発見）
- 次のアクション・ブロッカー

## 注意

- 言語: 日本語
- コミットハッシュがあればリンクする
- 人間のコメント欄（「人間さんの記述」セクション）は AI が書かない
