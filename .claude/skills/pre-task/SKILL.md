# Skill: pre-task

Run this before starting any task.

## Steps

1. **Archive stale wip/** — if any `docs/workflow/*/wip/` files remain from a previous completed task, move them to `archive/` now
2. **Update roadmap** — add the new task(s) under the current phase in `docs/roadmap.md`
3. **Read `docs/index.md`** — get an overview of what docs exist
4. **Read relevant history** — for the task's domain, read related files from:
   - `docs/journal/tasks/` (past task logs)
   - `docs/workflow/*/archive/` (past design decisions)
5. **State task breakdown** — list all subtasks atomically before touching any file. Wait for user to confirm or correct before proceeding.
