# Command: journal

今日の作業ログを書く（または更新する）。`.claude/rules/journal.md` の形式に従うこと。

## 手順

1. 今日の日付を確認（YYYY-MM-DD形式）
2. 作業ログを `docs/journal/tasks/NNN-task-name.md` に作成する
   - NNN は既存ファイルの連番の続き
3. `docs/journal/<today>.md` に本日のタスクログへのリンクを追記する
4. この会話の作業内容から以下を抽出してタスクログに記述する：
   - 実施したタスク（完了・進行中・新規）
   - 技術的決定事項（選択肢・選択・理由）
   - 学んだこと・気づき
   - 次のアクション・ブロッカー

## 注意

- 日次ファイルの感情・反省セクションは AI が書かない（人間が記入）
- コミットハッシュがあればリンクする
