# Journal Rules

Work logs and daily diary in Japanese.

## Structure

```
docs/journal/
├── YYYY-MM-DD.md        # daily: index of sessions + personal reflection
└── tasks/
    └── NNN-task-name.md # per-task work log
```

## Task Log (`tasks/NNN-task-name.md`)
- One file per task or work session
- Numbered sequentially (001, 002, ...)
- Written during or immediately after the task

### What to include
1. **Tasks** — done, in-progress, newly discovered
2. **Decisions** — options considered, choice made, why
3. **Learnings** — what worked, what didn't, insights
4. **Next** — next actions, blockers
5. Link commits with hashes where relevant

## Daily Diary (`YYYY-MM-DD.md`)
- Index of task logs created that day
- Personal reflection and emotions (written by human, not AI)
- AI writes only the index section

## When to Write
- Task log: after completing or pausing any meaningful work
- Daily diary index: at end of session
