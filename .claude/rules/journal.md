# Journal Rules

Daily work logs in Japanese.

## When to Write
- End of any work session (required)
- Key decisions made (required)
- Phase completion (required)

## What to Include
1. **Tasks** — done, in-progress, newly discovered
2. **Decisions** — options considered, choice made, why
3. **Learnings** — what worked, what didn't, insights
4. **Next** — next actions, blockers

## Format
- File: `docs/journal/YYYY-MM-DD.md`
- Language: Japanese
- Link commits with hashes where relevant
